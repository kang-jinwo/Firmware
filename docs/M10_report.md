# M10. 정리

**목표**: 2주 동안 한 것을 보고서 한 장과 학업계획서용 요약으로 정리한다.
**끝났다는 기준**: 계획서 11절의 형태로 정리된다.

이 단계의 글은 **전부 내가 쓴다.** 이 문서는 무엇을 어떤 순서로 쓸지만 안내한다.

## 1. 재료 모으기

쓰기 전에 아래를 한곳에 펼쳐 놓는다.

| 재료 | 어디 |
|---|---|
| 학습 기록 8개 (P1 ~ P8) | `log/P*.md` |
| 내가 한 질문과 해결 과정 | `log/QNA.md` |
| 타이밍 표 | `log/timing_table.md` |
| 검증 결과 | `python run.py test` 의 출력 |
| 내가 그린 그래프 | 내가 저장한 PNG |
| 내가 쓴 코드 | `tests/`, `tools/` |

## 2. 보고서 한 장 (`docs/report.md` 로 쓴다)

아래 제목을 그대로 쓰고, 각 항목을 2~4문장으로 채운다.

```
# 센서-모터 제어 펌웨어 구현과 검증

## 1. 무엇을 만들었나
(한 문단. 가상 모터, C 펌웨어, 자동 검증)

## 2. 구조
(그림 하나: 펌웨어 ↔ sensor_read / pwm_set ↔ 모터 모델. 경계를 둔 이유 한 문장)

## 3. 검증 결과
(검증 기준 표 V1~V6 과 내 테스트의 PASS/FAIL, 측정값)
(일부러 넣은 버그 B1~B5 를 내 테스트가 잡았는지)

## 4. 만난 문제와 한 일
(P1~P8 표: 문제 / 원인 / 한 일 / 남은 것. 한 줄씩)

## 5. 타이밍
(타이밍 표와 가정)

## 6. 하지 못한 것
(P6, P8 에서 남긴 것. 실제 보드에서 확인하지 못한 것)
```

4번 표는 학습 기록의 1번, 2번, 3번, 4번 항목을 한 줄로 줄이면 된다.

## 3. 학업계획서용 요약

계획서 11절의 비중을 따른다.

| 부분 | 분량 | 내용 |
|---|---|---|
| 1~3단계 (모터, 회로, 안정성) | 한 문장 | 전공 지식으로 모터 모델을 세웠다 |
| 4~5단계와 검증 | 중심 | 직접 짠 검증 코드, 주기 안에 끝나는지 계산, 문제를 만나고 푼 과정 |
| 마무리 | 두세 문장 | 부족했던 것, 그래서 배우려는 것 |

쓰는 순서:

1. 학습 기록 8개와 `log/QNA.md` 를 다시 읽고, **가장 오래 막혔던 것 두세 개**를 고른다. 전부 쓰지 않는다.
2. 고른 것마다 계획서 3절의 다섯 단계로 쓴다: 문제 → 공부한 것 → 적용 → 남은 어려움 → 앞으로 배울 것.
3. "남은 어려움"이 소프트웨어 쪽(주기를 지키는 것, 메모리, 여러 작업)으로 모이는지 본다. 모인다면 그것이 마무리 문장이 된다. 모이지 않는다면 실제로 모인 쪽으로 쓴다.

### 지킬 것

- **실제로 겪지 않은 어려움은 쓰지 않는다.** 이 저장소의 문서에 있는 설명을 옮겨 적지 않는다. 학습 기록과 `QNA.md` 에 남아 있는 내용만 쓴다.
- 숫자는 내가 돌려서 본 값만 쓴다.
- "AI가 기준 구현을 만들었고, 나는 그것을 분석하고 검증 코드를 직접 썼다"는 역할 분담을 숨기지 않는다. 무엇을 직접 했는지가 분명할수록 글이 믿을 만해진다.

## 4. 스스로 점검하는 질문

글을 쓰기 전에 아래에 소리 내어 답해 본다. 막히는 질문이 있으면 그 단계 문서로 돌아간다.

1. 펌웨어가 `motor.w` 를 직접 읽지 않고 `sensor_read()` 를 거치는 이유는? (M4)
2. P 제어는 왜 목표에 닿지 못하는가? (M4)
3. 적분은 무엇을 기억하는가? 자리를 잡았을 때 값은? (M5)
4. 고유값의 실수부와 허수부는 각각 무엇을 알려 주는가? (M5)
5. 도달 시간을 "처음 들어간 시각"으로 재면 안 되는 이유는? (M6)
6. 테스트가 전부 PASS면 버그가 없는가? (M6)
7. 이동평균을 길게 하면 좋아지는 것과 나빠지는 것은? (M7)
8. 고정소수점에서 q를 키우면 좋아지는 것과 위험해지는 것은? (M8)
9. 루프 실행 시간을 어떻게 추정했고, 어떤 가정을 했는가? (M8)
10. 주기를 넘겼을 때 응답이 느려진 진짜 이유는? (M8)
11. windup 은 왜 겉으로 보이지 않는가? (M9)
12. 이 프로젝트에서 지금의 지식으로 풀지 못한 것 하나와, 그것을 풀려면 배워야 할 과목은?

12번의 답이 학업계획서의 마지막 문장이다.
