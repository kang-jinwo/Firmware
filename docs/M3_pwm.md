# M3. PWM

**목표**: 전압을 켜고 끄기만 해서(PWM) 원하는 평균 전압을 만들 수 있음을 확인한다.
**끝났다는 기준**: 듀티 50 % PWM과 직류 6 V의 결과가 같음을 **내가 Python으로 그린 그래프**로 확인한다.

2. `sim/main.c` 의 `for` 문 안 (c) 부분 — 전압을 정하는 곳

## 2. 설명

### 왜 PWM인가

마이크로컨트롤러의 핀은 0 V 아니면 전원 전압, 두 가지만 낼 수 있다. 6 V를 "아날로그로" 만들려면 남는 6 V를 어딘가에서 열로 버려야 한다. 대신 스위치를 아주 빠르게 켜고 끄면, 켜져 있는 시간의 비율(듀티)만큼의 평균 전압이 된다. 스위치는 켜져 있을 때 전압 강하가 거의 없고 꺼져 있을 때 전류가 없어서 열이 거의 나지 않는다.

```
듀티 50 %, 주기 50 µs

12 V ┌────┐    ┌────┐    ┌────┐
     │    │    │    │    │    │        평균 = 12 × 0.5 = 6 V
 0 V ┘    └────┘    └────┘    └────
     0   25   50   75  100  125 µs
```

### 누가 평균을 내 주는가: 인덕터 (2단계: 회로이론)

모터의 R-L 은 저역통과 필터다. 차단 주파수는 R/(2π·L) = 1/(2π × 0.5 ms) ≈ 318 Hz.
PWM 주파수 20 kHz는 그보다 60배 이상 높아서 거의 다 걸러지고, 평균(직류 성분)만 전류로 나타난다.

시간으로 보면: 전류는 0.5 ms 시정수로 변하는데 PWM은 50 µs마다 뒤집힌다. 전류가 한쪽으로 가기도 전에 전압이 바뀌므로 전류는 평균값 주변에서 조금만 흔들린다 (리플).

리플의 크기: 켜져 있는 동안 인덕터에 걸리는 전압은 약 Vs·(1 − d), 그 시간은 d·T 이므로

```
Δi ≈ Vs · d · (1 − d) · T / L = 12 × 0.5 × 0.5 × 50e-6 / 0.5e-3 = 0.3 A
```

### 코드에서 한 가지 걸린 문제

시뮬레이션 간격이 1 µs이고 PWM 주기가 50 µs이니, 한 주기는 50칸이다. "칸마다 켜짐/꺼짐"으로만 하면 듀티를 1/50 = 2 % 단위로밖에 못 만든다. 속도로는 24 rad/s 단위다. 제어기가 듀티 0.337을 요청해도 0.32 아니면 0.34가 나간다.

그래서 `pwm_voltage` 는 경계에 걸친 칸에서 "그 칸 안에서 켜져 있던 비율"만큼의 전압을 돌려준다.

```c
double frac = on_steps - k;      // 예: on_steps = 16.85, k = 16 → 0.85
if (frac > 1.0) frac = 1.0;      // 완전히 켜진 칸
if (frac < 0.0) frac = 0.0;      // 완전히 꺼진 칸
```

실제 마이크로컨트롤러에서도 같은 문제가 있다. 타이머 클록이 16 MHz이고 PWM이 20 kHz이면 한 주기가 800칸이라 듀티 분해능은 1/800이다. PWM 주파수를 올리면 분해능이 떨어진다.

## 4. 생각해 볼 질문

**Q1.** PWM 주파수를 20 kHz에서 200 Hz로 낮추면 어떻게 될까? 먼저 예상하고 실험한다.
(실험: `sim/main.c` 의 `#define PWM_STEPS 50` 을 `5000` 으로 바꾸고 `python run.py M3`. 끝나면 되돌린다.)

<details><summary>▶ 답과 설명 보기</summary>

200 Hz는 차단 주파수 318 Hz보다 낮다. 인덕터가 더 이상 평균을 내 주지 못한다. 주기가 5 ms로 전기 시정수(0.5 ms)의 10배이므로, 켜져 있는 2.5 ms 동안 전류가 끝까지 올라갔다가 꺼진 동안 끝까지 내려온다.

시뮬레이션 결과: 전류가 −5.8 A ~ +6.0 A 사이를 오가고 (20 kHz일 때는 리플 0.3 A), 속도도 13 rad/s 폭으로 흔들린다. 평균 속도는 여전히 592 rad/s 근처다.

평균은 같은데 무엇이 문제인가? 저항에서 나는 열은 R·i² 의 평균이다. 평균 전류가 0.06 A여도 ±6 A로 흔들리면 열은 수천 배가 된다. 그래서 PWM 주파수는 "전기 시정수보다 충분히 빠르게" 잡는다. 20 kHz를 많이 쓰는 또 다른 이유는 사람 귀에 들리지 않기 때문이다 (모터에서 삐 소리가 나지 않는다).
</details>

**Q2.** 그래프에서 PWM일 때 전류가 음수로 내려가는 순간이 있다. 이상하지 않은가?

<details><summary>▶ 답과 설명 보기</summary>

평균 전류가 0.06 A인데 리플이 0.3 A이므로, 리플의 아래쪽 절반에서 음수가 된다. 스위치가 꺼진 동안 모터 단자가 0 V에 묶이면, 역기전력(약 6 V)이 전류를 반대 방향으로 민다. 모터가 잠깐 발전기처럼 동작해 브레이크가 걸리는 구간이다.

이 모델은 "꺼졌을 때 단자가 0 V에 이상적으로 연결된다"고 가정했다 (양방향 스위치). 다이오드 하나만 쓰는 간단한 회로에서는 전류가 음수가 되지 못하고 0에서 멈춘다. 그 차이는 이 프로젝트의 범위 밖이다 (계획서 12절: 소자 수준 모델은 하지 않는다). "모델은 가정 위에 서 있고, 어떤 가정을 했는지 알고 있어야 한다"는 것만 기억한다.
</details>

**Q3.** PWM과 직류 6 V의 속도가 같아지는 것은 어떤 성질 덕분인가?

<details><summary>▶ 답과 설명 보기</summary>

**선형성**이다. PWM 전압은 "직류 6 V" + "평균이 0인 ±6 V 사각파"로 나눌 수 있다. 선형 시스템에서는 입력을 나눠서 각각의 출력을 구한 뒤 더해도 된다 (중첩의 원리).

- 직류 6 V → 속도 592.7 rad/s
- 20 kHz 사각파 → 저역통과로 거의 다 걸러진다 → 전류 리플 0.3 A, 속도에는 거의 영향 없음

신호및시스템에서 배우는 "신호를 주파수 성분으로 나눠서 본다"는 생각이 바로 이것이다.
</details>
