# log/ — 학습 기록

이 폴더에는 기록이 두 종류 있다: 문제별 학습 기록(내가 쓴다)과 질문 기록 `QNA.md` (AI가 적고 내가 마무리한다).

문제 하나당 파일 하나. `TEMPLATE.md` 를 복사해서 `P1_gain.md` 처럼 이름을 붙인다.

- 내용은 **내가** 쓴다. 문서에 있는 설명을 옮겨 적지 말고, 내가 본 그래프와 내가 한 생각을 적는다.
- 실험한 **그날** 쓴다. 며칠 지나면 "무엇이 헷갈렸는지"를 잊는다. 학업계획서에 쓸 재료는 바로 그 부분이다.
- 5번(앞으로 배울 것)에 무엇을 쓸지 모르겠으면, 각 단계 문서 끝의 "남은 어려움" 항목을 읽고 **실제로 내가 이해 못 한 것만** 고른다.
